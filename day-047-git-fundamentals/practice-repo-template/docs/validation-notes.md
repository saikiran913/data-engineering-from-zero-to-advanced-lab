# Validation Notes

Use these notes to practise small documentation changes.

## Suggested Checks

- Row count check: compare expected and actual file lines.
- Key check: confirm `order_id` is populated.
- Status check: review values such as `COMPLETED`, `PENDING`, and `CANCELLED`.
- Amount check: confirm order amounts are numeric-looking values.

Keep notes clear and commit related documentation changes with related technical changes when they belong together.
