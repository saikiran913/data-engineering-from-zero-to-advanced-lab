# Git vs GitHub

| Git | GitHub |
|---|---|
| Version control system | Hosted collaboration platform |
| Works locally | Usually remote/web-hosted |
| Tracks commits | Hosts Git repositories |
| Command-line/tooling concept | Website, APIs, and collaboration features |

## Key Difference

Git records and inspects project history. GitHub hosts repositories and adds collaboration features.

Git does not require GitHub. GitHub uses Git. Other hosting platforms also exist.

## Common Misconceptions

| Misconception | Correction |
|---|---|
| Git and GitHub are the same | Git is the tool; GitHub is a hosting platform |
| A commit uploads work automatically | A local commit stays local until a remote operation happens |
| GitHub is required to use Git | Git can work entirely locally |
| Git is only for software engineers | Data Engineers use Git for SQL, scripts, configs, and documentation |
