## How Data Engineers Use These Examples

Data engineers use exception reports to make validation results practical. A simple failed check is helpful, but a review queue is better because it gives the reviewer the affected entity, rule, expected value, actual value, severity, and source context in one place.

The most important habit is to keep the report read-only. The exception queue should identify and explain issues. Corrections should happen only after investigation and approval through the proper process.
