Day 045 practice data

This directory contains small sample files for Bash pipe and redirection exercises.

customers_sample.csv contains generic customer rows.
orders_sample.csv contains generic order rows with repeated status values.
pipeline_log.txt contains generic INFO, WARN, and ERROR log lines.
status_values.txt contains deliberately unsorted repeated status values.
command_output_sample.txt shows normal and error-style message examples.

Use these files for safe command-line practice. Keep any generated output inside practice-output.
