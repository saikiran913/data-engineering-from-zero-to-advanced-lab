# Glossary

| Term | Simple meaning |
|---|---|
| `<` | Sends file content into stdin |
| `>` | Redirects stdout and can overwrite a file |
| `>>` | Appends stdout to a file |
| `2>` | Redirects stderr and can overwrite a file |
| `2>>` | Appends stderr to a file |
| `2>&1` | Sends stderr to the same place as stdout conceptually |
| Append | Add to the end of a file |
| Bash | Common POSIX-style shell |
| Command chain | Commands connected together |
| cut | Selects simple delimited fields |
| Error output | Error or warning messages |
| File descriptor | Number that represents a stream |
| Filter | Keep matching text |
| grep | Finds lines matching a pattern |
| Input redirection | Sends file content into a command |
| Overwrite | Replace existing file content |
| Pipe | Sends output of one command into another |
| Pipeline | A sequence of connected command stages |
| Pipeline stage | One command in a pipeline |
| Redirect | Send output to another place |
| Redirection | Shell syntax for changing stream destinations |
| sort | Sorts text lines |
| Standard error | Error stream |
| Standard input | Input stream |
| Standard output | Normal output stream |
| stderr | Short name for standard error |
| stdin | Short name for standard input |
| stdout | Short name for standard output |
| tee | Displays output and writes it to a file |
| Text stream | Text flowing between commands |
| uniq | Collapses adjacent duplicate lines |
| wc | Counts lines, words, or bytes |
