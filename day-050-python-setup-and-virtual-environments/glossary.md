# Glossary

| Term | Simple meaning |
|---|---|
| `.py` | Python script file extension |
| `.venv` | Common virtual environment folder name |
| Activation | Making a virtual environment active in a shell |
| Current working directory | Folder the terminal is currently using |
| Deactivation | Leaving the active virtual environment |
| Dependency | Package a project needs |
| Dependency isolation | Keeping project packages separate |
| Entry point | Code path where a script starts |
| Environment | Python interpreter and available packages |
| Executable | Program path used to run Python |
| Global environment | System-wide Python environment |
| Interpreter | Program that runs Python code |
| Module | Importable Python unit conceptually |
| Package | Reusable installed Python code |
| Package isolation | Separating packages by project |
| pip | Python package installer |
| `pip list` | Command that lists installed packages |
| Project environment | Python environment for one project |
| Python | General-purpose programming language |
| Python 3 | Modern Python major version |
| Python executable | Specific Python program being run |
| REPL | Interactive Python prompt |
| Requirements file | File documenting dependencies |
| `requirements.txt` | Common dependency documentation file |
| Reproducibility | Ability to recreate setup reliably |
| Script | Reusable Python file |
| Standard library | Python modules included with Python |
| `sys.executable` | Python value showing executable path |
| `sys.version` | Python value showing version details |
| System Python | Python installed for the wider system |
| Virtual environment | Isolated project Python environment |
