# Python REPL

REPL means Read-Evaluate-Print Loop.

## Useful For

- quick syntax checks
- tiny experiments
- interpreter verification

## Minimal Examples

```python
print("Python is working")
```

```python
2 + 3
```

## Not Ideal For

- reusable project logic
- long workflows
- version-controlled pipeline code

## REPL Versus Script

| REPL | Script |
|---|---|
| Interactive | Saved file |
| Temporary | Reusable |
| Good for quick checks | Better for project work |
| Harder to review later | Easy to track in Git |
