# Beginner Python Project Template

This template shows a small Python project layout for Day 050.

## Requirements

- Python 3
- No third-party packages required

## Create Virtual Environment

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## Verify

```bash
python --version
python -m pip --version
```

## Run

```bash
python src/main.py
```

## Deactivate

```bash
deactivate
```

Do not commit `.venv/` or local secret files.
