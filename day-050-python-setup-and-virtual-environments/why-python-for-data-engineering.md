# Why Python for Data Engineering?

Python is common because it is readable, general purpose, and has a large ecosystem.

## Common Roles

- automation
- file and data processing
- testing and validation
- API integration conceptually
- database clients conceptually
- cloud SDKs conceptually
- orchestration tools conceptually

| Data Engineering task | Python role |
|---|---|
| File validation | Check file metadata/content |
| API ingestion | Request/parse responses conceptually |
| Database automation | Run queries/connectors conceptually |
| Pipeline utilities | Reusable processing functions conceptually |
| Data quality | Validation checks |
| Orchestration | Task logic conceptually |

Python is one tool, not the whole Data Engineering stack. SQL remains essential. Shell and Git remain complementary skills.
