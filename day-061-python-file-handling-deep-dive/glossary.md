# Glossary

| Term | Meaning |
|---|---|
| Append mode | `a` mode, which adds text to an existing file. |
| CSV | A comma-separated text format for tabular data. |
| Context manager | `with` pattern that cleans up a resource automatically. |
| DictReader | CSV reader that returns each row as a dictionary. |
| DictWriter | CSV writer that accepts dictionaries and explicit fields. |
| Encoding | Rule used to turn text into bytes; UTF-8 is common. |
| Fieldname | A CSV column name. |
| File handle | Python object representing an opened file. |
| Input file | Source data that a pipeline reads and preserves. |
| JSON | Structured text format for objects and lists. |
| JSONDecodeError | Error raised for malformed JSON syntax. |
| Line iteration | Reading a text file one line at a time. |
| Output file | Generated result owned by the pipeline. |
| Parse | Convert file text into Python values. |
| Path | Location of a file or folder. |
| Pathlib | Python module that provides `Path`. |
| Quarantine | Hold a bad source aside for investigation. |
| Row count | Number of data rows in a dataset. |
| Schema | Expected columns and their meaning. |
| Source lineage | Record of where data came from. |
| UTF-8 | Widely used text encoding. |
| Validation | Checking structure or values against rules. |
| Write mode | `w` mode, which creates or replaces a file. |
