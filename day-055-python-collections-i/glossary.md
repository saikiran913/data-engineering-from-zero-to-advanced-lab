# Glossary

| Term | Simple meaning | Beginner example |
|---|---|---|
| Append | Add one item to list end | `items.append("d")` |
| Collection | One value holding multiple values | list of files |
| Extend | Add multiple items to a list | `items.extend([...])` |
| Homogeneous collection | Items share same meaning | row counts |
| Immutable | Cannot be changed after creation | tuple positions |
| Index | Item position | `0` |
| Indexing | Access by position | `items[0]` |
| Insert | Add item at position | `items.insert(1, "x")` |
| List | Mutable sequence | `["a", "b"]` |
| List mutation | Changing a list | replace or append |
| Membership | Check presence | `"PASS" in results` |
| Mixed-type collection | Different value types together | tuple record |
| Mutable | Can be changed | list |
| Negative indexing | Count from end | `items[-1]` |
| Nested sequence | Sequence inside sequence | list of tuples |
| Ordered collection | Position matters | pipeline steps |
| Pop | Remove and return item | `items.pop()` |
| Positional field | Field meaning by index | index 0 = order ID |
| Record sequence | Ordered values for a record | order tuple |
| Remove | Remove matching item | `items.remove("x")` |
| Sequence | Ordered collection | list or tuple |
| Sequence contract | Documented meaning/order | field position map |
| Sequence length | Number of items | `len(items)` |
| Shallow copy concept | Surface-level copy of list | `items.copy()` |
| Slice | Selected range | `items[0:2]` |
| Slice start | First included index | `0` |
| Slice step | Interval between selected items | `items[::2]` |
| Slice stop | First excluded index | `2` |
| Slicing | Selecting a range | `items[:2]` |
| Tuple | Immutable sequence | `("ORD-1", "PASS")` |
| Tuple unpacking | Assign tuple values to names | `order_id, status = record` |
| Zero-based indexing | First item is index 0 | `items[0]` |
