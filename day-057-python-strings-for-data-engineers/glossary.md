# Glossary

| Term | Meaning |
| --- | --- |
| Canonical value | One approved standard representation |
| Case standardisation | Applying a documented case rule |
| Cleaned string | String after approved cleaning |
| Delimiter | Character separating controlled fields |
| Deterministic | Same valid input gives same output |
| Empty string | String with zero characters |
| F-string | Formatted string literal for readable output |
| Field count | Number of parsed parts |
| Find | Method returning position or `-1` |
| Idempotent | Repeating a rule does not change result further |
| Immutable | Cannot be changed in place |
| Join | Combine strings using a delimiter |
| Leading whitespace | Whitespace at the start |
| None | Missing Python value, distinct from text |
| Normalisation | Making values consistent by a rule |
| Parse | Give meaning to controlled text parts |
| Raw string | Original supplied text |
| Replace | Substitute matching text deliberately |
| Split | Separate text into parts |
| Standardisation | Deriving an approved canonical value |
| String | Text value in Python |
| Substring | Text contained inside another string |
| Trailing whitespace | Whitespace at the end |
| Whitespace-only string | Text containing only whitespace |
