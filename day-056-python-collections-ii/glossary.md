# Glossary

| Term | Meaning |
| --- | --- |
| `None` value | A present key with no value |
| Deduplication | Removing repeated values when that is appropriate |
| Dictionary | Mutable mapping of unique keys to values |
| Difference | Values in one set but not another |
| Direct lookup | Required access using `record["key"]` |
| Expected keys | Fields a record contract expects |
| Extra key | Observed field not listed in the expected contract |
| Get | Optional lookup method, `.get()` |
| Intersection | Values shared by two sets |
| Key | Meaningful dictionary field name |
| Key contract | Agreement about required and optional keys |
| Key-value pair | One named field and its value |
| KeyError | Error raised for absent direct lookup |
| List of dictionaries | Several named records in a list |
| Lookup | Finding a value by key |
| Lookup table | Mapping used to find a related value |
| Mapping | Structure associating keys with values |
| Membership | Checking whether a key or set value exists |
| Missing key | Field absent from a dictionary |
| Mutation | Changing a mutable collection |
| Nested data | Dictionary or list stored inside another collection |
| Nested dictionary | Dictionary stored as a value |
| Observed keys | Fields actually supplied by a record |
| Optional key | Field permitted to be absent |
| Optional lookup | Safe intentional lookup with `.get()` |
| Record shape | Documented structure of a record |
| Required key | Field that must be supplied |
| Set | Collection of unique values |
| Union | Values from either set |
| Uniqueness | No repeated equal values |
| Value | Data stored for a dictionary key |
