# Glossary

| Term | Simple meaning |
|---|---|
| Automatic merge | Git combines changes without a text conflict |
| Branch | Named line of Git history |
| Branch comparison | Reviewing differences between branches |
| Branch history | Commits reachable from a branch |
| Branch pointer | Branch name pointing to a commit |
| Branch workflow | Safe process for branch-based work |
| Collaboration | Working with others through structured changes |
| Conflict marker | Text showing competing merge versions |
| Conflict resolution | Choosing final content after a conflict |
| Current branch | Branch currently checked out |
| Default branch | Repository's main line of work |
| Divergence | Branches have different commits after a shared point |
| Fast-forward merge | Merge that moves a branch pointer forward |
| Feature branch | Branch for focused work |
| HEAD | Current Git position conceptually |
| History graph | Visual view of commits and branch labels |
| Local branch | Branch stored in local repository |
| Main branch | Common name for default branch |
| Merge | Bring one branch's work into another |
| Merge base | Shared starting point between branches conceptually |
| Merge commit | Commit recording combined histories |
| Merge conflict | Git needs human help combining changes |
| Remote branch concept | Branch on a shared remote, covered later |
| Resolved file | File edited to remove conflict markers |
| Source branch | Branch being merged from |
| Target branch | Branch receiving the merge |
| Unmerged path | File Git reports as needing conflict resolution |
