# Command Line Cheatsheet

## Where Am I?

```bash
pwd
```

## What Is Here?

```bash
ls
ls -l
ls -a
```

## Move

```bash
cd folder
cd ..
cd ~
```

## Create Safe Practice Items

```bash
mkdir practice
touch practice/notes.txt
```

## Inspect

```bash
cat file.txt
head file.txt
tail file.txt
file file.txt
wc -l file.txt
```

## Help

```bash
command --help
man command
command -v command
```

## Symbols

| Symbol | Meaning |
|---|---|
| `.` | current directory |
| `..` | parent directory |
| `~` | home directory in many POSIX shells |
| `/` | POSIX root or path separator |

## Safety

Use a dedicated practice folder. Do not practise destructive commands in Day 044.
