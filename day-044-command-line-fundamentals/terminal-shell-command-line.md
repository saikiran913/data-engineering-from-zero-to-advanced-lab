# Terminal, Shell, and Command Line

| Term | Meaning |
|---|---|
| Terminal | Application or window used to enter commands |
| Shell | Program that interprets commands |
| Command line | Text-based way of interacting with the system |
| Command | Instruction given to the shell |

## Prompt

A prompt is the text shown before you type a command. It often gives clues about the user, machine, and current folder.

```text
user@machine:~/project$
```

This is a generic example, not a real computer name.

## Command Shape

```text
command [options] [arguments]
```

Examples:

```bash
pwd
ls
ls -l
cd sample-data
```

## Data Engineering Connection

Before working with scripts, logs, SQL files, or data folders, a Data Engineer often needs to answer:

- Where am I?
- What files are here?
- Which folder should I enter?
- What file should I inspect?
- How do I ask this command for help?
