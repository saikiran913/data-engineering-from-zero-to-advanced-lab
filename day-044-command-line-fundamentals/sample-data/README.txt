Day 044 practice data

This directory contains small, safe files for command-line practice.

customers_sample.csv contains generic customer rows.
orders_sample.csv contains generic order rows.
pipeline_notes.txt contains simple data-pipeline notes.
log_sample.txt contains generic timestamped log lines.
folder-map.txt shows a common project folder structure.

Use these files to practise listing directories, reading small text files, previewing CSV files, checking file type, and counting lines.
