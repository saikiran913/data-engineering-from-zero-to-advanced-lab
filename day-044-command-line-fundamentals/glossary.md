# Glossary

| Term | Simple meaning |
|---|---|
| Absolute path | Full path from root or drive |
| Argument | Value passed to a command |
| Bash | Common POSIX-style shell |
| Command | Instruction typed into a shell |
| Command line | Text-based way to interact with a computer |
| Command prompt | Text shown before you type a command |
| Command syntax | Expected command structure |
| Current location | Folder the shell is currently using |
| Current working directory | Same idea as current location |
| Directory | Folder containing files or folders |
| Executable command | Command the shell can run |
| File | Stored item such as CSV, text, or Markdown |
| File extension | Ending such as `.csv` or `.txt` |
| File system | Organised structure of files and directories |
| Flag | Option that changes command behaviour |
| Folder | Another word for directory |
| Hidden file | File often hidden from normal listing |
| Home directory | User's usual starting folder |
| Manual page | Detailed command help page |
| Option | Command modifier such as `-l` |
| Parent directory | Directory one level above current directory |
| Path | Address of a file or directory |
| Path separator | Character between path parts |
| POSIX | Family of Unix-like command-line conventions |
| PowerShell | Windows shell and command environment |
| Quoted path | Path wrapped in quotes |
| Relative path | Path starting from current directory |
| Root directory | Top of a file-system tree |
| Shell | Program that interprets commands |
| Terminal | Application window for command-line work |
| Working directory | Folder commands use as current location |
| Zsh | Common POSIX-style shell |
