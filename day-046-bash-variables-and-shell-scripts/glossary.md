# Glossary

| Term | Simple meaning |
|---|---|
| `$#` | Number of positional arguments |
| `$0` | Script name |
| `$1` | First positional argument |
| `$?` | Previous command's exit status |
| `$@` | All positional arguments |
| `-d` | Test that checks for a directory |
| `-f` | Test that checks for a regular file |
| `-s` | Test that checks for a non-empty file |
| `-z` | Test that checks for an empty string |
| Argument | Value passed to a script or command |
| Bash | A common Unix-style shell |
| Command substitution | Capturing command output with `$(...)` |
| Comment | Text ignored by the shell, often starting with `#` |
| Conditional | Logic that runs based on a test |
| Double quotes | Quotes that allow variable expansion |
| Dry run | Preview of what would happen |
| Environment variable | Variable made available to child processes |
| Exit code | Number that reports command result |
| Exit status | Another name for exit code |
| Expansion | Replacing a variable reference with its value |
| File test | A check such as `-f` or `-d` |
| For loop | Repeats commands for values |
| Idempotency | Safe repeated runs do not create unexpected side effects |
| Input validation | Checking inputs before processing |
| Local variable | Variable used in the current shell or script |
| Loop | Repetition of commands |
| Parameter | Value supplied to a script or command |
| Positional parameter | Numbered argument such as `$1` |
| Quote | Character used to protect or control text expansion |
| Script | File containing reusable shell commands |
| Script argument | Value passed when running a script |
| Shebang | First script line naming the intended shell |
| Shell variable | Named value inside a shell |
| Single quotes | Quotes that keep text literal |
| stderr | Error output stream |
| stdout | Normal output stream |
| Variable | Named value reused later |
| Variable assignment | Storing a value with `name="value"` |
