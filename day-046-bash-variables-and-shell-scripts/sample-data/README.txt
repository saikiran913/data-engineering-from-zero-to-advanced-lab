Day 046 sample data supports Bash variable and shell script exercises.

The files are generic and safe for local practice.

customers_sample.csv contains simple customer rows.
orders_sample.csv contains simple order rows.
pipeline_log.txt contains generic INFO, WARN, and ERROR log lines.
status_values.txt contains repeated unsorted status values.
file_catalog.txt lists relative sample file paths for review examples.

Scripts should read these files without changing them.
Any generated learner output should go into practice-output/.
