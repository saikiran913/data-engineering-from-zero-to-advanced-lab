# Glossary

| Term | Simple meaning | Beginner example |
|---|---|---|
| Accumulator | Variable that collects a running value | `total_rows += row_count` |
| Accumulator variable | Name used for a running total | `total_errors` |
| Bounded loop | Loop with a clear end | `attempt <= 3` |
| Break | Stop the loop early | `break` |
| Continue | Skip to next iteration | `continue` |
| Counter | Variable that counts events | `pass_count += 1` |
| Cross-product concept | Every outer item paired with every inner item | files x checks |
| Enumerate | Get position and item | `enumerate(files, start=1)` |
| Fail-fast | Stop after critical issue | break on `FAIL` |
| For loop | Loop over known items | `for file_name in files:` |
| Full scan | Process every item | count all results |
| Infinite loop | Loop that never ends | missing update in `while` |
| Iterable | Value Python can visit item by item | list of files |
| Iteration | One pass through loop | one file reviewed |
| Iteration count | Number of loop passes | three items, three passes |
| Loop | Repeated code | `for` or `while` |
| Loop body | Indented repeated code | print inside loop |
| Loop variable | Current item name | `file_name` |
| Nested loop | Loop inside another loop | files then checks |
| Off-by-one error | Count boundary mistake | `range(1, 5)` misses 5 |
| Range | Number sequence helper | `range(1, 6)` |
| Running total | Total updated over time | `total_rows` |
| Sequence | Ordered items | list or tuple |
| Termination condition | Rule that stops a loop | `attempt <= 3` becomes false |
| Validation summary | Final count of outcomes | PASS/REVIEW/FAIL totals |
| While loop | Loop while condition is true | `while attempt <= 3:` |
