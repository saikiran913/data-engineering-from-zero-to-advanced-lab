# Glossary

| Term | Simple meaning | Beginner example |
|---|---|---|
| Assignment | Giving a value to a name | `row_count = 100` |
| Boolean | True/false value | `is_valid = True` |
| Boolean literal | Direct boolean value | `True` |
| Conversion | Changing type | `int("100")` |
| Data type | Kind of value | `str`, `int` |
| Dynamic typing | Variable can refer to different types over time | `value = 1`, then `value = "1"` |
| Empty string | Text with no characters | `""` |
| Float | Decimal number | `42.5` |
| Identifier | Valid Python name | `source_name` |
| Integer | Whole number | `100` |
| Literal | Value written directly in code | `"orders"` |
| Missing value | Value is not available | `None` |
| None | Python no-value object | `last_error = None` |
| NoneType | Type of `None` | `type(None)` |
| Numeric string | Text that looks numeric | `"100"` |
| Reassignment | Giving a variable a new value | `count = 1`, then `count = 2` |
| Scalar | Single simple value | `100` |
| snake_case | Lowercase words with underscores | `record_count` |
| String | Text value | `"orders"` |
| Truthiness | How Python treats values as boolean-like | `bool("")` |
| Type | Category of value | `int` |
| Type awareness | Knowing current and expected type | check `type(value)` |
| Type conversion | Changing value type | `float("42.5")` |
| Type drift | Same field arrives with changed type | float yesterday, string today |
| Variable | Name that refers to a value | `source_name` |
| Value | Actual data in code | `120` |
| Whitespace string | String containing spaces | `" "` |
| `bool` | Boolean type/converter | `bool(1)` |
| `float` | Float type/converter | `float("1.5")` |
| `int` | Integer type/converter | `int("10")` |
| `str` | String type/converter | `str(10)` |
| `type()` | Function that shows type | `type(record_count)` |
