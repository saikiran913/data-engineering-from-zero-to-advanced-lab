# Glossary

| Term | Meaning |
| --- | --- |
| `__main__` | Name used when module runs directly |
| `__name__` | Current module name |
| Exception | Runtime error object |
| Fail-fast | Stop/report critical invalid input |
| Fallback | Explicit recoverable alternative |
| Import | Bring module code into another file |
| Main guard | Conditional direct-run entry point |
| Module | Reusable Python file |
| Orchestration | Coordinating helper functions |
| Package | Directory grouping modules |
| Runtime error | Failure while code runs |
| Syntax error | Invalid Python structure |
| Validation | Pre-operation contract check |
| ValueError | Invalid value for operation |
