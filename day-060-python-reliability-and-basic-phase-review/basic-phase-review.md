# Basic Phase Review

| Days | Main foundation |

| 052 | Conditions and Boolean logic |
| 053 | Loops |
| 054 | Functions and scope |
| 055 | Lists and tuples |
| 056 | Dictionaries and sets |

| 058 | Dates and times |

```text
environment → read input → parse → clean → convert types → validate → transform → handle expected failures → summarize
```

You are ready when you can run scripts, read errors, use values and collections, write functions, process simple strings/dates/files, parse basic CSV/JSON, and structure reusable code.
