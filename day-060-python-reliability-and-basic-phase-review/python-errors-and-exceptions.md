# Python Errors and Exceptions

A syntax error is invalid Python structure and prevents execution. A runtime exception occurs while running, such as `int("abc")`, a missing dictionary key, or a missing file. A logical error, such as a wrong threshold, may run without an exception.

A traceback shows the call path, exception type, and message. Common beginner exceptions are `ValueError`, `TypeError`, `KeyError`, `IndexError`, and `FileNotFoundError`.
