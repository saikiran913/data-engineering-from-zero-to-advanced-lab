# Glossary

| Term | Simple meaning |
|---|---|
| Argument | Value supplied when calling a function. |
| Clean record | New normalized record used by later stages. |
| Composition | Connecting focused functions in order. |
| Configuration parameter | Caller-provided rule such as a threshold. |
| Default parameter | Value used when the caller omits an optional argument. |
| Dependency | Input or service a function needs. |
| Deterministic | Same input produces same output. |
| Function contract | Documented inputs, output, errors, and side effects. |
| Function interface | Function name and callable parameters. |
| Helper function | Small function with one focused job. |
| Helper module | File grouping related helper functions. |
| Hidden dependency | Needed value not visible in parameters. |
| Idempotent | Repeating produces the same final result. |
| Input contract | Required shape and types of incoming values. |
| Keyword argument | Argument supplied by parameter name. |
| Mutable default | Default list/dictionary shared between calls. |
| Optional parameter | Parameter with a documented default. |
| Orchestration | Calling stages in the right pipeline order. |
| Output contract | Guaranteed shape and type of returned result. |
| Parameter | Named input in a function definition. |
| Pipeline stage | One focused step in a data flow. |
| Positional argument | Argument matched by its position. |
| Pure function | Function without side effects or hidden state. |
| Raw record | Original source dictionary. |
| Required parameter | Parameter the caller must supply. |
| Return contract | Consistent rule for a function's return value. |
| Return value | Data sent back by `return`. |
| Reusable function | Function usable in more than one context. |
| Side effect | Change outside a returned value, such as printing. |
| Single responsibility | One clear job per function. |
| Transformation function | Function that converts or normalizes data. |
| Validation function | Function that checks a rule. |
