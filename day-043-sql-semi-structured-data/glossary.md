# Glossary

| Term | Simple meaning |
|---|---|
| Array | Collection of zero or more values |
| Array element | One value inside an array |
| Array expansion | Turning array elements into rows |
| Array grain | What one expanded array row represents |
| Blank value | Empty string value |
| Element type | Type of an array element |
| Explicit null | Key exists with null value |
| Extraction | Reading a value from a nested path |
| Failed cast | Value cannot convert to expected type |
| Flattening | Turning nested values into columns or rows |
| JSON | Text format for objects, keys, values, and arrays |
| JSON key | Name used to find a value |
| JSON object | Collection of key-value pairs |
| JSON path | Address for a nested value |
| JSON value | Stored value such as string, number, object, array, boolean, or null |
| Malformed JSON | JSON text with invalid syntax |
| Missing key | Expected key does not exist |
| Nested field | Field inside a nested object |
| Nested object | Object inside another object |
| Nested schema | Expected structure inside JSON |
| Nested schema drift | Nested structure changes over time |
| Object value | JSON value that is another object |
| Optional path | Path allowed to be missing |
| Parent grain | What one source row represents |
| Parent key | Key that identifies the source row |
| Required path | Path that must be present |
| Scalar | Single value such as text or number |
| Scalar extraction | Reading one scalar value |
| Schema-on-read | Interpreting structure when queried |
| Semi-structured data | Data with structure that may vary |
| Typed extraction | Extracting or casting to a target type |
| Unexpected key | Key not listed in the expected contract |
| Value type | Expected kind of value |
