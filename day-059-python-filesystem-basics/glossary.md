# Glossary

| Term | Meaning |
| --- | --- |
| Absolute path | Complete environment-specific location |
| Context manager | `with` structure that cleans up resource |
| CSV | Delimited rows and columns format |
| CSV header | Names for CSV columns |
| CSV row | One CSV record |
| Current working directory | Directory used for relative paths |
| Delimiter | Character separating fields |
| DictReader | CSV reader returning dictionaries |
| Directory | Container for paths |
| Encoding | Rule for converting bytes/text |
| File | Named stored content |
| File format | Structure/rules of content |
| File handle | Open file resource |
| Filesystem | Files and directories arrangement |
| JSON | Structured text format |
| JSON array | JSON ordered collection |
| JSON object | JSON named mapping |
| `json.load` | Parse JSON file to Python value |
| `json.loads` | Parse JSON string to Python value |
| Newline | Line-ending character |
| Optional file | File allowed to be absent |
| Parser | Code that interprets format |
| Path | pathlib path object |
| pathlib | Standard path library |
| Relative path | Location based on working directory |
| Required file | File that must exist |
| Resolve | Produce absolute path representation |
| Script-relative path | Path built from script location |
| Stem | Filename without suffix |
| Structured file | File with defined shape |
| Suffix | Filename extension |
| Text file | File read as text |
| UTF-8 | Common text encoding |
| Working directory | Current terminal/program directory |
