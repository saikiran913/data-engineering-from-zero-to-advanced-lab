# Glossary

| Term | Simple meaning |
|---|---|
| Ahead | Local branch has commits remote does not |
| Behind | Remote has commits local branch does not |
| Branch protection concept | Rule that protects shared branches, covered later |
| Clone | Create local copy from remote |
| Code review | Human review of proposed changes |
| Collaboration workflow | Team process for shared changes |
| Divergence | Local and remote both have different new commits |
| Fetch | Download remote references without integrating |
| Hosting provider | Service that hosts repositories |
| Local branch | Branch in your local repository |
| Local repository | Repository on your machine |
| Merge readiness | Change is reviewed and validated enough to merge |
| Origin | Common default remote name |
| Pull | Fetch plus integrate into current branch |
| Pull request | Review proposal on a hosting platform |
| Published commit | Commit pushed to a remote |
| Push | Publish local commits to remote |
| Remote | Named connection to another repository |
| Remote branch | Branch in a remote repository |
| Remote repository | Shared repository outside local working copy |
| Remote state | Current known state of remote references |
| Remote-tracking branch | Local reference to remote branch state |
| Repository URL | Location used to clone or connect to a repository |
| Review | Inspection before merge |
| Source branch | Branch proposing changes |
| Synchronisation | Keeping local and remote work aligned |
| Target branch | Branch intended to receive changes |
| Tracking branch | Local branch connected to an upstream |
| Upstream | Remote branch tracked by local branch |
