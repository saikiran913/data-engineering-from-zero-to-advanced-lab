# Glossary

| Term | Meaning |
| --- | --- |
| Aware datetime | Datetime with timezone context |
| Boundary | Start or end of a window |
| Date | Calendar date |
| Date arithmetic | Adding/subtracting duration |
| Datetime | Date and clock time together |
| Daylight-saving time | Seasonal local clock rule |
| Duration | Elapsed amount of time |
| Event latency | Processing time minus event time |
| Event time | When source event happened |
| Exclusive boundary | Boundary value not included |
| Format code | Symbol for parse/format |
| Formatting | Datetime to text conversion |
| Freshness | How recent data is |
| Inclusive boundary | Boundary value included |
| Ingestion time | When data arrived |
| ISO format | Clear ISO-style date/time text |
| Local time | Time in local timezone |
| Naive datetime | Datetime without timezone |
| Parsing | Text to datetime conversion |
| Partition date | Date used to group data |
| Processing time | When pipeline processed data |
| Source timezone | Timezone intended by source |
| Stored timezone | Timezone used to store value |
| `strftime` | Datetime to text method |
| `strptime` | Text to datetime method |
| Time | Clock time |
| Time contract | Documented timestamp rules |
| Timedelta | Duration object |
| Timestamp | Date/time value or text |
| Timezone | Time context by zone/offset |
| Timezone-aware | Having timezone context |
| Timezone offset | Difference from UTC |
| UTC | Common global reference |
| Window | Defined time range |
| ZoneInfo | Standard-library timezone class |
